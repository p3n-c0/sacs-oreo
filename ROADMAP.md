# Roadmap

This roadmap keeps Oreo powerful while preserving an authorized, non-destructive assessment model.

## MVP / Variant 1

- Authorization-gated CLI
- Same-host crawler
- Passive response analysis
- Safe header, cookie, HTTPS, CORS, sensitive file, directory listing, robots, sitemap, reflected input, and SQL error pattern checks
- JSON and HTML reports
- Core unit tests

## Next Priorities

- Config file support for repeatable scans
- Scan profiles for quick, standard, and deep safe assessment modes
- Request rate limiting and crawl delay controls
- Custom headers and cookies for authenticated authorized scans
- Proxy support for assessment workflows
- Improved technology fingerprinting
- Better evidence grouping and finding de-duplication
- Branded report theme for SecureAfrica Cyber Solutions
- GitHub release workflow and packaged distributions

## Later

- Safe CVE correlation based on detected technologies
- SARIF export for security engineering workflows
- Baseline comparison across scan runs
- Plugin architecture for approved safe checks
- More complete test fixtures with local vulnerable demo targets
